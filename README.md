# 📝 To-Do Web App

**Version:** 5.5

A simple and responsive To-Do Web App built using HTML, CSS, and JavaScript.

## 🌐 Live Demo 
https://wut-11.github.io/TO-DO-APP/

## ✨ Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Edit Tasks
* Responsive design
* Clean and simple interface
* Local Storage support

## 🛠️ Built With

* HTML
* CSS
* JavaScript

## 🚀 Future Plans

* Task categories
* Dynamic viewing for different viewports
* Drag and Drop Cards/ Pin a Task
* Sub-Tasks
* Task Search & Counter
* Focus Timer/ Pomodoro
