# 📝 To-Do Web App

**Version:** 3.0

A simple and responsive To-Do Web App built using HTML, CSS, and JavaScript.

## ✨ Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Responsive design
* Clean and simple interface
* Local Storage support

## 🛠️ Built With

* HTML
* CSS
* JavaScript
